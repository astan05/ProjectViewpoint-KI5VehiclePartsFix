# Changelog

## 1.3

- Supports the updated Viewpoint model layout (68 floats per draw), while retaining support for the previous 60-float layout.
- Keeps the Rolling Hills compatibility fix.

## 1.2

- Fixes a conflict with Viewpoint Rolling Hills that could make vehicle parts disappear after its terrain system activates.
- Preserves the existing adaptive visibility fix when Rolling Hills is not installed.

## 1.1

- Restores the interior roof in the KI5 1982 Porsche 911 Turbo using its existing KI5 roof model.
- Keeps the existing adaptive visibility fix unchanged.

## 1.0

Initial public release. Adaptive vehicle-part visibility fix for Project Viewpoint. No configuration required.
